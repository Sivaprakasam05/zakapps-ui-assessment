# 🚘 MotorVault – Car E-Commerce Website

MotorVault is a modern, responsive car shopping website developed as part of the ZakApps UI Developer Assessment. The application allows users to browse premium cars, view detailed vehicle information, manage a shopping cart, register/login, and place orders through an intuitive user interface.

## 🚀 How to Run the Project

### Method 1: Open Directly

1. Download or clone the repository.
2. Open `index.html` in a web browser.

### Method 2: Using VS Code Live Server

1. Open the project in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
